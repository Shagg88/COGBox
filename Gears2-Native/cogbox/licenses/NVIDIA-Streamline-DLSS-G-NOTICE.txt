NVIDIA DLSS Frame Generation, NVIDIA Streamline and NVIDIA Reflex
=================================================================

COGBox's ports can use NVIDIA DLSS Super Resolution / DLAA on NVIDIA GeForce RTX graphics cards and NVIDIA DLSS Frame
Generation (experimental) on GeForce RTX 40 / 50 series cards. This uses the following NVIDIA software, redistributed
unmodified in object code form in the release's shared\ folder (0.4.9; up to 0.4.8 next to each port program), which
COGBox puts on each game's search path, as NVIDIA allows:

      NVIDIA RTX SDKs License (v. March 14, 2024) - see licenses\dlss-sdk\LICENSE.txt.

  sl.interposer.dll, sl.common.dll, sl.dlss_g.dll, sl.reflex.dll, sl.pcl.dll
      NVIDIA Streamline SDK 2.14.16 - Copyright (c) 2023 NVIDIA CORPORATION. All rights reserved.
      MIT licence - see licenses\streamline-sdk\license.txt (third-party parts of Streamline:
      licenses\streamline-sdk\3rd-party-licenses.md).

      NVIDIA RTX SDKs License - see licenses\streamline-release\nvngx_dlss.license.txt.
