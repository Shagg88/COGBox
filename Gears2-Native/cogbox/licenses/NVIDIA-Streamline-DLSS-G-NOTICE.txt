NVIDIA DLSS Frame Generation, NVIDIA Streamline and NVIDIA Reflex
=================================================================

COGBox's ports can use NVIDIA DLSS Frame Generation (experimental) on NVIDIA GeForce RTX 40 / 50 series graphics
cards. This uses the following NVIDIA software, redistributed unmodified in object code form next to each port program
(Gears1\port, Gears2\port-tu6, Gears3\port-tu6, Judgment\port) as NVIDIA allows:
