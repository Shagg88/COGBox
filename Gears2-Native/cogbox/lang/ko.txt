Which screen the game uses. Default = the main screen. = 게임이 사용할 화면입니다. 기본값: 주 화면.
Each frame waits for your screen's next refresh, so the picture never tears. With G-Sync / FreeSync the screen follows the game below its refresh rate. The frame rate is capped a little under your screen's refresh rate (half of it with frame generation), which keeps the extra input lag small. Off = frames are shown at once (lowest lag, may tear). = 각 프레임이 화면의 다음 주사율 갱신을 기다리므로 화면이 찢어지지 않습니다. G-Sync / FreeSync를 쓰면 화면이 주사율 아래에서 게임을 따라갑니다. 프레임 레이트는 화면 주사율보다 약간 낮게 제한되며(프레임 생성 시에는 절반), 추가 입력 지연을 작게 유지합니다. 끔: 프레임이 즉시 표시됩니다(지연 최소, 화면 찢김이 생길 수 있음).
Sets the graphics boxes in one go. Original = the game as on the console. Change any box afterwards and the preset shows Custom. = 그래픽 항목을 한 번에 설정합니다. 원본: 콘솔과 같은 게임. 이후 항목을 하나라도 바꾸면 프리셋이 사용자 지정으로 표시됩니다.
How much detail the game draws: 1x: 1280x720 as on the console, 2x: 2560x1440, 3x: 3840x2160 (4K), 4x: 5120x2880. Real detail, not an upscale. Match my monitor: the smallest scale that covers the screen, resampled to its exact size. 1080p: drawn at 720p and upscaled to the screen with sharpening - fast, for weaker graphics cards; softer than real detail. = 게임이 그리는 디테일의 정도입니다. 1x: 콘솔과 같은 1280x720, 2x: 2560x1440, 3x: 3840x2160(4K), 4x: 5120x2880. 업스케일이 아닌 실제 디테일입니다. 내 모니터에 맞춤: 화면을 덮는 가장 작은 배율로 그린 뒤 화면의 정확한 크기로 리샘플링합니다. 1080p: 720p로 그린 뒤 선명도를 높여 화면에 업스케일합니다. 빠르며 성능이 낮은 그래픽 카드에 적합하지만 실제 디테일보다 부드럽습니다.
