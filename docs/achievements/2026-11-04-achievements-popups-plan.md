# Achievements Part 2: Unlock Popups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Achievement unlocks show an animated popup in the player's chosen style (Xbox 360, modern Xbox, PS5 trophy),
with colour presets, position, a replaceable sound, and a Platinum popup at 100 %.

**Architecture:** All decisions and the animation curves are pure C++17 (`achievements_popup_logic.{h,cpp}`,
unit-tested). `AchievementPopup` (an SDK `AchievementNotificationDialog`) replaces `LazyAchievementToast`, keeps its
"attached only while showing" behaviour, and draws one frame per game frame through three style files using ImGui
draw lists. Settings are launcher **Shared** options (one value for all games, kept in `settings.ini [General]`, in
the F1 menu automatically) passed as `--cogbox_ach_*` options.

**Tech Stack:** C++23 / clang (games), C++17 / mingw (launcher), Dear ImGui (SDK overlay), Catch2 (`gn_tests`),
Windows `PlaySoundW` (winmm, loaded at run time).

**Spec:** `docs/achievements/2026-11-04-achievements-popups-design.md`

## Global Constraints

- No Microsoft / Sony logo, font, artwork or sound in the repo or package. Shapes are drawn with ImGui draw lists;
  fonts are loaded from the PC; the sound is generated by us.
- Pure logic files use only the standard library (C++17), namespace `xenos::ach`.
- Popup timing (revised in Task 3 from reference clips; the spec's Animation section is the authority): `PopupDuration`
  X360 6.1 s, Xbox 7.3 s, PS5 5.7 s; popups queue one after another. All three show the achievement's own icon
  (X360: the X turns into it; Xbox: it flips to the trophy / diamond; clipped to a circle in both).
- Grade: GP <= 30 Bronze, 31-74 Silver, >= 75 Gold; Gears 1 (`0x4D5307D5`) ids 13 and 19 Gold.
- Rare: `known && percent < 10`.
- Colour presets, in this order (index = launcher choice): Dark `#24262B` (border `#3C3F46`), Red `#9E1B22`, Green
  `#107C10`, Blue `#0E5AA7`, Purple `#6B2FA3`, Orange `#C25A0C`, Pink `#B4246E`, Teal `#0E7C7B`, Grey `#4B4F56`, Gold
  `#A07A12`.
- Positions, in this order: Default, Top left, Top centre, Top right, Bottom left, Bottom centre, Bottom right.
  Default = bottom centre (360, Xbox), top right (PS5).
- Size: designed for 1080p; scale = window height / 1080 clamped to [0.6, 2.0]; edge margin 48 px x scale.
- Game options: `cogbox_ach_style` (`x360`|`xbox`|`ps5`, default `x360`), `cogbox_ach_colour` (preset name, lower
  case, default `dark`), `cogbox_ach_position` (`default`|`top_left`|`top_centre`|`top_right`|`bottom_left`|
  `bottom_centre`|`bottom_right`), `cogbox_ach_sound` (bool, true), `cogbox_ach_hide` (bool, false),
  `cogbox_ach_test_keys` (bool, false: F9 sample popup, F10 sample Platinum).
- Launcher Shared options (Display tab until part 4): `AchievementStyle` {Xbox 360, Xbox, PlayStation},
  `AchievementColour` {the 10 names}, `AchievementPosition` {the 7 names}, `AchievementSound` (Bool, on),
  `HideAchievementPopups` (Bool, off). `settings.ini` keeps choice indices, as every launcher option does.
- Sound file: `<COGBox>\assets\sounds\achievement-<style>.wav` if present, else `achievement.wav`. `<COGBox>` =
  `--cogbox_dir`; without it, two folders up from the exe (all ports are `<COGBox>\<Game>\<port>\`).
- Fonts (ruling vs spec, see Task 4): `C:\Windows\Fonts\segoeui.ttf` + `seguisb.ttf`; else `tahoma.ttf` (Wine /
  Proton ship one); else `arial.ttf`; else ImGui's built-in font. Korean / Chinese merged from `malgun.ttf`,
  `msjh.ttc`, `msyh.ttc` when present.
- Never play or control the games yourself; the player runs every in-game check. Back up any exe replaced in
  `Downloads\COGBox` as `<exe>.pre-popups` first.
- Commits: author `Flippage <10948118+Flippage@users.noreply.github.com>`, trailer `Co-Authored-By: Claude Opus 5.5
  <noreply@anthropic.com>`, branch `feature/achievements`, local only.

## Review Focus

- A popup pushed while another shows waits its turn; ten unlocks at once all show, in order, without overlapping.
- An unlock pushed while "Hide achievement popups" is on shows nothing later if the setting is turned off (no backlog).
- The PS5 Platinum entry follows only the unlock that completes the game, not a repeat of an already-unlocked one.
- A name in Russian / Korean / Chinese fits and draws (or shows boxes), never empty, never past the popup's edge.
- At window heights 720 and 2160 the popup keeps its proportions and stays inside the screen in every position.

### Task 2: Animation timeline

**Files:**
- Modify: `achievements_popup_logic.{h,cpp}`, `tests/layer0_achievements_popup_test.cpp`

**Interfaces:**
- Produces:
  ```cpp
  constexpr float kPopupSeconds = 5.0f;
  struct PopupFrame {
    float alpha = 0;        // whole popup 0-1
    float icon_scale = 0;   // orb / badge (may overshoot to 1.12)
    float bar = 0;          // pill / box width 0-1 (0 = only the icon)
    float slide = 1;        // 0 = in place, 1 = fully off screen (PS5: to the right)
    float text_alpha = 0;
    float shine = -1;       // Xbox trophy shine 0-1, -1 = none
    bool finished = false;
  };
  PopupFrame PopupTimeline(PopupStyle style, float seconds);
  ```
  Keyframes (ease-out cubic on the way in, ease-in cubic on the way out; linear for alpha):
  ```
  X360: alpha 0->1 [0,0.15]; icon_scale 0->1 [0,0.15]; bar 0->1 [0.15,0.5]; text_alpha 0->1 [0.4,0.6]; slide 0.
        out: text_alpha 1->0 [4.5,4.65]; bar 1->0 [4.5,4.85]; alpha 1->0 [4.8,5.0].
  Xbox: alpha 0->1 [0,0.1]; icon_scale 0->1.12 [0,0.18] then 1.12->1 [0.18,0.28]; bar 0->1 [0.2,0.5];
        text_alpha 0->1 [0.4,0.65]; shine 0->1 [0.7,1.2]; slide 0.
        out: text_alpha 1->0 [4.5,4.6]; bar 1->0 [4.5,4.8]; alpha 1->0 [4.75,5.0].
  Ps5:  slide 1->0 [0,0.4]; alpha 0->1 [0,0.2]; icon_scale 1; bar 1; text_alpha = alpha.
        out: slide 0->1 [4.6,5.0]; alpha 1->0 [4.6,5.0].
  seconds >= 5.0: finished, alpha 0.
  ```
